Goal Oriented Action Planning with Smart Objects

AI tech demo, Unreal Engine

Instead of a separate action class, the planner compiles every smart object in the scene and reads preconditions and effects off the objects themselves. Agents query the planner with a current state and a goal state, get back an ordered list of objects to interact with, and step through it using an internal state machine so the behaviour reads as believable.
