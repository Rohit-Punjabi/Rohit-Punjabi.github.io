Player Telemetry & Analytics Platform

Shrapnel · shipped in production

Shows Data · Engineering · Product

C++MongoDBTypeScript ReactUnreal 5.3REST APIs

The question

Which weapons, maps, and mechanics were unbalancing matches, and where were players hitting bugs we couldn't reproduce?

Data

Live gameplay event streams from thousands of play sessions: kills, weapon usage, movement paths, and power up pickups, collected in engine and stored in a MongoDB cloud backend.

What I did

I worked with design and QA to define the metric schema and KPIs, built the in engine collection layer in C++, then led development of a TypeScript and React dashboard so designers could slice sessions without writing queries.

Designers moved from gut feel to data driven balance decisions, engineers found bug conditions from telemetry instead of repro attempts, and the KPIs fed straight into roadmap priorities.

Inventory Analytics & Demand Forecasting

Wholesale clothing retailer · shipped as a desktop app

Shows Data · Engineering · Product

PythonPandasstatsmodels PlotlyStreamlitExcelClaude

The question

What is actually selling, what is dead stock, and how much of each product should the store order in the coming months?

Data

About 50 monthly Excel workbooks spanning 4+ years: inconsistent column names, quantities stored as text, and a product naming change that split sales histories in two.

What I did

I built a Pandas pipeline that unifies every workbook into one tidy table with automated data health checks, matches renamed products by style code, selects the best forecast model per product, and validates accuracy by backtesting on held out months. Then I wrapped it in a desktop app the team runs themselves, where forecasts feed safety stock, reorder points, and a monthly order plan. I used Claude as my coding partner throughout, which took it from idea to working product fast.

Key insight

The data health checks caught quantities saved as text like "55 PCS", which had silently hidden about 38% of all sales and distorted which products looked like best sellers.
